# Web Samples

Three premium, interactive landing pages. Each folder is a self-contained static site deployed as its own Vercel project.

| Folder | Brand | Interactive centrepiece |
|---|---|---|
| `ich-textilles/` | Ich Textilles (textiles) | Weave Studio: live warp/weft fabric renderer with draped layer-mask preview |
| `furneco/` | Furneco (furniture) | Armchair configurator: timber, upholstery and day/dusk/night room light mask |
| `sj-builders/` | SJ Builders (architecture) | Facade visualizer: six building systems toggled as 2D layer masks, with build sequence |

All icons are inline monochrome SVG in a single accent colour per site. No emoji, no external JS libraries.
